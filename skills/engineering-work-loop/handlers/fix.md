# Handler — fix

Work item type: `fix`  
Branch: `fix/<issue#>-<slug>`

## When

Label `bug` or explicit fix issue with Loop AC and reproduction steps.

## Default tier

`assist` — open PR for human review unless Loop AC includes test verify command and diff within thresholds.

## Steps

1. Reproduce in worktree.
2. Minimal fix + test from Loop AC verify.
3. Open **draft** PR with Work Fix Report and AC evidence.
